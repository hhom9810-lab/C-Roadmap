## Главные идеи {#ideas}

1. **Тип — это договор о данных и поведении.** `class` — ссылочный и изменяемый по умолчанию, `struct` — копируемое значение, `record` — класс или структура с равенством по значению, `interface` — только контракт.
2. **Скрывайте данные, открывайте поведение.** Поля — закрытые, наружу — свойства и методы; уровень доступа выбирайте минимальный из достаточных.
3. **Порядок инициализации важен.** Сначала инициализаторы полей производного класса, затем конструктор базового, затем тело конструктора производного. Не вызывайте виртуальные методы из конструкторов.
4. **Ресурсы освобождает `Dispose`, а не сборщик мусора.** `using` гарантирует вызов даже при исключении; финализатор — только страховка для неуправляемых ресурсов.
5. **События держат подписчиков.** Подписка — ссылка издателя на подписчика; забытая отписка — самая частая утечка памяти.
6. **Полиморфизм — это `virtual` и `override`.** `new` лишь скрывает член и зависит от статического типа переменной.
7. **Композиция чаще лучше наследования.** Наследуйте для отношения «является» и общей реализации, интерфейсы — для контрактов.
