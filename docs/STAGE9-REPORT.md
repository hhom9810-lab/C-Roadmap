## Lighthouse (доступность)

Запуск: Lighthouse 12 на Chromium через локальный http-сервер (`file://` Lighthouse не принимает; файл тот же). Итог по экранам: «Сегодня» 100, «Путь» 100, «Справочник» 100, «Профиль» 100, «Помощь» 100, практика `p5-async` 100, тема `p7-questions` 100, тема `p5-async` 96 (см. ниже). Порог ТЗ — не ниже 90.

Что исправлено:
- Светло-оранжевый акцент `--here` использовался как цвет текста (контраст 2,65). Добавлен токен `--here-ink` (светлая тема `#855200`, контраст ≥ 5,5; в тёмных темах равен `--here`); применён в «Зачем это нужно», метке проекта и таймере.
- `role="listitem"` на ссылках сегментов фаз («Сегодня») убран вместе с `role="list"` контейнера (недопустимая роль для `<a>`).
- Узлы «Пути»: убран `aria-label`, расходившийся с видимым текстом; состояние («Не начата», «текущая», «закрыта: …») читается скрытым `.sr-only`-текстом внутри кнопки.
- «Лестница рангов» и «Достижения»: неполученные элементы были с `opacity .5–.6` (контраст 2,2–2,6) — подняты до `.9–.94`, различие остаётся за счёт серого и рамки.

Остаток 96 на теме `p5-async`: Lighthouse снимает контраст в середине анимации появления блока кода (цвета смешаны с фоном: `#7a619d` вместо `#c69bff`); токены кода проверены `tests/contrast.py` (проблем 0).

## Производительность и «ленивый рендер»

- Страница всегда отрисовывает только текущую тему (`#content`), остальные не попадают в DOM.
- Разбор всех 91 страниц при старте занимает ≈ 165 мс из ≈ 480 мс холодного запуска (файл 4,5 МБ; при замедлении CPU ×4 — ≈ 1,9 с). Ленивый разбор **не внедрён намеренно**: прогресс, фазы, «Путь», карточки, поиск и `tests/labcheck.py` (читает `LABDATA` всех 242 блоков) требуют чекбоксов, критериев и блоков всех страниц сразу; риск поломать ключи прогресса выше выигрыша в 0,1–0,3 с. Куча JS ≈ 16–23 МБ.
- Виртуализация списков не нужна: самые длинные списки (дерево «Пути» — 91 узел, «Справочник» — 140 записей) отрисовываются без заметных задержек. Lighthouse-«performance» (≈ 35) измеряет симуляцию медленной 4G для файла 4,5 МБ и для офлайн-файла из `file://` не показателен.
